# P005 — Game Modes

## Modes contractuels
- DUEL_1V1
- FFA
- TRAINING
- RANKED
- EVENTS

## Lifecycle commun
`WAITING → STARTING → RUNNING → ENDING → RESETTING → CLOSED`

## Contrat GameMode
Chaque mode fournit :
- règles ;
- capacité ;
- équipe(s) ;
- condition de victoire ;
- gestion de l'arène ;
- récompenses ;
- événements autoritatifs ;
- procédure de reset.

## Roadmap gameplay
1. Duel 1v1
2. FFA
3. Training
4. Ranked
5. Events

Les modes historiques Fallen Kingdoms, SheepWars, Totem et Fight Club restent des modules distincts à intégrer après validation du Core et du pipeline d'arènes.
